# DicomVision v3.2.3

DicomVision v3.2.3 adds PET quantification throughout the viewer while preserving the stable 3D rotation behavior from the clean baseline.

## Highlights

- Added PET quantitative display support for SUV/SUL/%ID/g workflows, including unit selection, PET min/max range, PET pseudocolor, color bars, hover values, and corner labels across Stack, MPR, Montage/Layout, Compare, and PET/CT Fusion.
- Added backend PET quantification context and validation for unit normalization, decay correction, unsupported dynamic/gated PET handling, PET auto range, fusion rendering, pseudocolor, corner info, and segmentation statistics.
- Added PET/CT Fusion display controls for PET overlay and standalone PET pseudocolor so fused studies can use PET-specific unit/range settings without disturbing CT viewing.
- Added stable PET segmentation metrics in the MPR segmentation panel, including MTV, voxel count, SUV/SUL mean/max/peak, TLG gating for reliable FDG cases, effective threshold, min, and standard deviation.
- Improved MPR threshold segmentation rendering so the backend physical contour and outer threshold rectangle remain aligned after 3D rotation, editing, drag, resize, and redraw interactions.
- Improved right-side segmentation panel stability by keeping the PET threshold summary at a fixed two-line height while statistics update.
- Regenerated frontend API contracts to match the new backend PET metadata fields and segmentation statistics responses.
- Expanded regression coverage for PET quantification, pseudocolor, PET viewer state, fusion rendering, MPR segmentation geometry, toolbar activation, and segmentation panel metrics.
