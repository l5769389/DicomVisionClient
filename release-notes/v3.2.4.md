# DicomVision v3.2.4

本次更新重点完善 PET/CT、MPR、序列平铺和后端影像渲染链路，修复快速交互时的画面跳变、状态不同步和派生视图显示不一致问题。

## 影像浏览与交互

- 重构影像帧呈现流程，使像素、窗宽窗位、方向、比例尺、四角信息、测量和标注按同一帧原子切换，避免新信息覆盖旧图像。
- 改进 CT/PET Stack 调窗调度，拖动过程持续接收后端完整影像，松手后以最终无损帧收敛。
- 修复 MPR 移动或旋转十字线时的闪烁和回跳；同一批次的受影响窗格全部准备完成后再一起切换。
- MPR 伪彩会在创建时继承同序列 2D 视图，并统一应用到 Axial、Coronal 和 Sagittal 三个正交窗格。
- 改进四角信息和伪彩条布局，长字段仅在确实被截断时显示完整内容。

## 序列平铺

- 新增独立的后端快速瓦片渲染链路，不生成不需要的四角信息、测量或标注图层。
- 修复窗模板和伪彩只更新工具栏、没有刷新平铺影像的问题；最终瓦片整批完成后原子替换。
- 支持跨宫格实时调窗，并确保最终请求优先于尚未执行的预览请求。
- 平移和缩放在平铺视图中即时反馈；调窗、PET 定量映射和伪彩仍全部由后端生成。
- 改进平铺信息摘要与展开详情；展开层覆盖影像区域，不再压缩影像网格。

## PET 与 PET/CT Fusion

- 修复 PET 平铺无法独立加载，以及独立 PET 与同序列平铺强度范围、单位和控制上限不一致的问题。
- PET 平铺直接读取权威显示配置，并与同序列独立 PET 双向同步定量显示状态。
- 优化 PET/CT 四宫格默认伪彩、伪彩应用目标、PET MIP 显示和活动窗格状态切换。
- 调整 PET 覆盖层透明度语义：`0%` 完全显示 PET，`100%` 完全隐藏 PET，并避免服务端响应造成滑块回跳。
- 融合影像、透明度和导出合成由后端生成，前端不执行 LUT、调窗或像素融合。
- 坐标系不匹配提示支持在当前融合标签页内关闭。

## 正确性、兼容性与性能

- 序列优先依据 `ImagePositionPatient` 的物理位置排序，并统一 Stack、Montage、MPR、3D 和 Fusion 使用的几何描述。
- 修复非等距 Pixel Spacing、PET 原始切片与标准化体数据混用、几何缓存失效及 Fusion 导出遗漏 PET 图层等问题。
- 对多帧 DICOM、混合方向、重复位置和不规则层距增加明确的能力限制，避免静默产生不可靠结果。
- 优化系列内容键、PET 单位映射、体数据和瓦片缓存，减少首次 Fusion 与 PET Montage 的重复计算。
- 服务端渲染使用不可变快照和串行批次调度，抑制过期 revision，减少快速交互中的状态竞争。

## 桌面体验

- macOS 使用系统原生红黄绿窗口按钮，放置在左侧品牌区上方，标签栏可完整使用右侧空间。
- Windows 保持现有右侧窗口控制布局。
- 调窗图标改为更明确的左白右黑水平渐变。
