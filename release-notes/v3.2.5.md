# DicomVision v3.2.5

本次更新重点提升质量分析的可信度、复杂 DICOM 序列的错误反馈，以及 2D/MPR/4D 视图在 resize、reset 和快速交互时的稳定性。

## MTF 与 FWHM 质量分析

- 重构点源 MTF 计算，支持径向以及 W/H 两个方向的 MTF50、MTF10 和 FWHM。
- FWHM 改为半高左右交点插值；没有完整交点时明确显示不可测，不再生成虚假有限值。
- MTF 阈值只在 Nyquist 范围内首次向下穿越时给出结果；超出数字采样上限时显示 `> Nyquist`。
- 支持矩形 ROI、各向异性 PixelSpacing、亮点与暗点、线性背景和亚像素点源中心。
- 小 ROI 会在计算时自动补足；低信噪比或零频响应不稳定时尽量返回带质量警告的结果。
- 不可恢复的分析失败会说明具体原因和重新选择 ROI 的建议，不再只显示 HTTP 状态码。
- 影像上仅显示 MTF ROI 与复制、删除操作；曲线、指标、警告和失败原因统一显示在右侧结果区。

## MPR、3D 与 4D 兼容性

- MPR、3D、4D 快捷按钮和序列右键菜单在选中序列后均可点击。
- 对切片不足、空间坐标缺失、方向混合、位置重复、不规则层距、PixelSpacing 不一致和多帧数据给出明确弹窗说明。
- 4D 必须包含至少两个有效相位，并且每个相位都能够构建 MPR；否则不会进入空白视图。
- 创建或首帧渲染失败时自动清理未完成的 View，并合并重复错误提示。

## 影像显示稳定性

- 修复 2D 视口调整大小后偶发模糊、缩放比例错误或影像不再居中的问题。
- reset 与初始显示使用一致的物理尺寸 contain-fit 计算，正确处理非正方形 PixelSpacing。
- 未进行手动平移、缩放、旋转或翻转的视图会在容器变化后自动重新适配；用户变换仍会被保留。
- 调窗预览继续由后端生成，并统一使用全尺寸高质量影像，减少按下、拖动和松开时的清晰度跳变。

## 桌面端交互

- 桌面视图统一使用右侧操作区，移除顶部操作按钮位置设置。
- 普通 2D、MPR、PET/CT Fusion 和 4D 使用一致的工具与二级内容区布局。
- 旧设置中的顶部工具栏选项会被安全忽略，不影响其他用户偏好。
